# Demo flow (routes)

`/` → `/demo` (redirect) → `/r/<demo-id>` snapshot → `/taste` → `/opportunities` → `/opportunities/<hid>` (Decision Lab, pursue/reject) → `/actions` (approve) → `/memory`.
Owner: `/login` (email OTP) → `/app` → `/app/restaurants/new` → `/r/<id>` → Run analysis.
Health: `/api/health`. Live verification (signed in): `/api/qloo/verify`.
